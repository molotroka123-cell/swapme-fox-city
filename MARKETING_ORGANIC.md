## 14-day zero-ad-spend sprint

- Days 1–2: F5 playtest, verify every advertised mechanic, capture 15–20 real gameplay clips; validate all site links on mobile.
- Days 3–4: Publish one genuine Fox Flight challenge clip and one Prague city clip to owned accounts. Respect platform rate limits.
- Days 5–6: Publish an original tycoon how-to video and link the relevant guide.
- Day 7: Compare visits and actual Roblox session starts **only if attribution has been configured**. Otherwise report link clicks as unavailable.
- Days 8–9: Release creator kit and invite a small number of relevant creators individually with context and no mass DMs.
- Days 10–11: Publish one authentic Prague city devlog in communities that allow it. Ask for design feedback, not forced engagement.
- Days 12–13: Make follow-up clips based on genuine comments and player suggestions.
- Day 14: Review real retention, player feedback and creator responses; repeat only formats that show positive results.

## Measurement / definition of done

**Site:** Pages resolve with HTTP 200 after GitHub Pages deployment; all internal links work; mobile layout is usable; canonical tags and sitemap match; share button works; no auto-redirect.

**Traffic:** Site sessions and referral source require a consent-appropriate analytics setup (not currently implemented). UTM strings alone do not prove visits, players or revenue.

**Roblox:** Track game visits, session starts, first-play bounce, average session length, D1/D7, friend invites, cosmetic conversion using Roblox Creator Analytics and real Share Links where supported.

**Content:** Keep source footage, publish dates, channel links, real view counts and actual game traffic. No guaranteed virality or invented ROI.
